Informe de Cambios: feat: Implementación inicial de UI para generador de avatares AI

Se ha añadido la interfaz de usuario básica para el generador de avatares con IA.

Detalles del Commit

  • Configuración inicial de la página principal (page.tsx) con un componente Dropzone para la carga de imágenes.
  • Creación del componente Dropzone (dropzone.tsx) con manejo de arrastrar y soltar, validación de archivos (tipo, tamaño, resolución) y previsualización de imágenes.
  • Definición de estilos con tailwind-variants para el Dropzone (dropzone-styles.ts).
  • Inclusión de utilidades (utils.ts) para la gestión de clases CSS con clsx y tailwind-merge.
  • Configuración de la integración con la API de Gemini (gemini.ts) para futura comunicación.
  • Definición de tipos y esquemas de validación (definitions.ts) para los estilos de avatares y las solicitudes/respuestas de la API.
  • Actualización de .gitignore para ignorar directorios de reportes y archivos del agente, y .env.example para la clave API.
  • Adición de nuevas dependencias (@google/generative-ai, clsx, tailwind-merge, tailwind-variants) en package.json y pnpm-lock.yaml.

Impacto: Estos cambios sientan las bases para la funcionalidad principal del generador de avatares.
